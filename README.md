# Cyberpunk 2088: Neon Protocol 🌆

A retro cyberpunk terminal adventure RPG built with the assistance of **GitHub Copilot** as an AI pair programmer.

Built for **MLH Global Hack Week: Builders Week** — *Challenge: Use GitHub Copilot to Build a Simple Application*.

---

## 🎮 Game Overview
In **Cyberpunk 2088: Neon Protocol**, you step into the boots of a rogue Netrunner tasked with infiltrating the high-security megacorp vault of Arasaka to neutralize a rogue AI core threatening the global grid.

### Features:
- 👾 **ASCII Art UI & Colors:** Atmospheric terminal UI styled like an 80s Cyberdeck HUD.
- ⚡ **Dynamic State Management:** Real-time tracking of Health Points (HP), Credits (¢), Cyberdeck models, and an interactive inventory.
- 🔐 **ICEBreaker Hacking Mini-Game:** Quick memory sequence decryption puzzle simulating biometric intrusion.
- 🔀 **Branching Narrative Paths:** Multiple pathways (Ripperdoc upgrades, Under-Net recon, or frontal assault) leading to different game endings.

---

## 🤖 Built with GitHub Copilot
GitHub Copilot acted as an AI pair programmer throughout development:
1. **Scaffolding Data Models:** Prompting Copilot to design the `Player` class, state properties, and dynamic HUD status printer.
2. **Hacking Logic Generation:** Using Copilot inline comments to generate the interactive ICEbreaker memory puzzle algorithm and countdown timer.
3. **Dialogue & Storyline Trees:** Guiding Copilot to author atmospheric cyberpunk dialogue and decision branching.

---

## 🚀 How to Play

### Prerequisites
- Python 3.8+ (no third-party dependencies required).

### Run the Game
```bash
python game.py
```
Follow the on-screen terminal prompts to make your choices and breach the Arasaka mainframe!
